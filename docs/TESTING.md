## 自动化覆盖

`tests/proof.test.mjs` 使用 `node:test`，包含 19 项测试：

| 类别 | 断言 |
| --- | --- |
| 主链路与公式 | 真实快照六路证据存在，N+1 日线、原字段独立复算一致；支持/不支持/因果未知并存 |
| 数据缺失/失败 | 指数接口失败后相对表现为空并降为未知；缺日线、重复日期停止计算 |
| 数值极端 | PE null 不补零；负 PE 不作常规估值；零分母不生成 Infinity；涨跌幅 0 保留为有效值 |
| 时间边界 | 盘中/16时后选择不同完整交易日；估值过期降为未知 |
| 源冲突 | 显式构造同日报价差异超过阈值，行情证据标记冲突 |
| 业务错误 | HTTP 200 + `code=4001` 不作成功；无静默重试；无密钥进入原始凭证 |
| 合规边界 | 买卖建议、保证收益、未来必涨和英文 buy 被拦截；普通历史主张允许 |
| 模型幻觉 | 非原文子串、未注册工具指标、数字字符串不能通过规划校验 |
| 模型失败 | 缺模型/HTTP 503 明确失败，不回退为假 AI |
| SSRF | 客户端本地地址、任意主机和额外端口拒绝 |
| 模型协议 | 模拟兼容 JSON 能生成合法计划；仅为协议测试，不代表真实模型语义准确 |
| 计划防篡改 | HMAC 有效票据可读，篡改或不同密钥拒绝 |

实际执行：19/19 通过；TypeScript 类型检查通过；生产构建通过。若后续代码改动，应按提交版本重跑。

## 真实数据接口验证

原始响应完整保存在 `data/sample-run.json`（无密钥），抓取时间见文件。实际成功调用扶摇交易日历、贵州茅台前复权日线、沪深 300 日线、市盈率 TTM 快照和行情快照，以及 iFinD MCP `stock_highfreq_quotes`（`600519.SH`、最新价/涨跌幅、`real_time`）。

样例窗口：2026-10-21 至 2026-10-28，5 个交易日区间，6 根日线。原始字段计算的区间个股涨幅约 1.6080%，相对基准约 2.2904 个百分点，成交额比约 0.8626 倍，PE TTM 约 20.4282 倍。它们是该次样例，不是当前行情或投资结论。

扶摇元数据就绪时点与 iFinD 行时点存在日期不一致，产品实际报告 `time_mismatch`，没有伪装成“交叉核验成功”。

## 明确的验证限制

- 真实 LLM 是否实测、采用什么模型，以真实 `model_record` 和交付状态为准；模拟响应不能算通过。缺密钥时自定义 AI 路径明确失败。
- 正则规则不是完整金融内容审核器，尚未覆盖所有隐喻、规避、否定语境和多语言表达。
- 每实例内存限流不是全局额度约束；流量增加前需要持久化配额与认证。
- 故障演练是 UI 中的人工注入，与纯函数/适配器自动测试互补，不能当作真实上游故障。
- 没有进行真实研究员配对试验，未验证效率提升、漏检下降或愿付费意愿。
