# 证研 · 投研结论核验台

把一段 A 股研究观点变成逐条可核验的主张：**原文 → AI 结构化计划 → 人工确认 → 金融数据取证 → 确定性核验 → 人工复核 → 带来源导出**。

- Web 产品：https://zhengyan-investment-proof.zihanwork0711.chatgpt.site
- 交付版本：研究原型 v1.0（2026-10-29，Asia/Shanghai）
- 详细产品设计：[docs/PRODUCT.md](docs/PRODUCT.md)
- AI 使用与修正记录：[docs/AI_USAGE.md](docs/AI_USAGE.md)
- 测试与验证：[docs/TESTING.md](docs/TESTING.md)

## 5 分钟操作

1. 默认直接进入浅色桌面核验工作台，首页展示明确标注采集时间的回放样例。观点输入、证据凭证、人工复核和导出均在同一工作区；「产品介绍」保留此前的视频展示页。
2. 点击「刷新示例证据」实时调用扶摇和 iFinD。固定示例无需 LLM 密钥，页面明确标记为固定规划。
3. 点击任一 E1–E6 证据入口，查看计算公式、字段路径、源时点、抓取时间、请求 ID 和完整原始响应。
4. 对每条主张选择「确认核验记录」或「需修订」，填写备注。在「核验记录」查看浏览器本地最近 8 条记录。
5. 导出 Markdown 研究记录或 JSON 原始证据。未逐条复核的导出会标为草稿；人工确认未知结论不会把未知变成支持。
6. 在「连接设置」填入 OpenAI 兼容模型的服务、模型名、API Key，再输入自己的观点运行完整 AI 主链路。临时密钥只保存在页面内存，刷新即消失，不进入记录或导出。
7. 使用底部故障演练按钮测试接口失败、两源冲突、数据过期与合规拦截；人工注入的视图始终标识为演练。

## 本地启动

要求 Node.js >= 22.13，推荐 Node 24。

```bash
npm ci
cp .env.example .dev.vars
# 编辑 .dev.vars，填入你有权使用的服务密钥（每行 KEY="value"）
npm run dev
```

打开终端打印的地址，默认 http://127.0.0.1:5173 。开发基于 React 19 / TypeScript / Vinext，生产运行于 Cloudflare Workers。保留 starter 的 Sites 构建与鉴权集成；普通 Next.js 服务可复用 UI 与核心模块，但应为 `getRuntime` 注入相同环境变量。

```bash
npm test
npm run typecheck
npm run build
```

`npm run capture:sample` 是显式刷新真实回放数据的开发命令，会修改 `data/sample-run.json`；不在构建时隐式调用接口。

## 环境变量

| 变量 | 作用 | 是否必需 |
| --- | --- | --- |
| `FUYAO_API_KEY` | 扶摇只读金融数据 | 在线取证必需 |
| `IFIND_API_KEY` | iFinD MCP 报价交叉检查 | 可选；未配置显式标记单源风险 |
| `LLM_API_KEY` | OpenAI Chat Completions 兼容模型访问 | 自定义观点的 AI 规划必需；也可页面临时提供 |
| `LLM_BASE_URL` | 模型服务基础地址，默认 `https://api.openai.com/v1` | 可选 |
| `LLM_MODEL` | 账号实际可调用的模型 ID，无默认猜测值 | AI 规划必需 |
| `PLAN_SIGNING_SECRET` | 服务端 HMAC 签名，防止修改 AI 计划与模型使用记录 | AI 规划必需；建议随机 32 字节以上 |

密钥不写入源代码、浏览器包或 `.openai/hosting.json`。`.dev.vars` 与 `.env*` 默认被 Git 忽略，唯一例外是没有真实值的 `.env.example`。线上通过 Sites 原生 secret 配置。公开评审版使用用户授权的金融服务密钥，LLM 配置状态可在设置中查看。不要向研究文本提交账户、持仓、客户信息等敏感材料。

## 产品选择与 AI 的增量价值

目标用户是负责盘后点评的 A 股研究员与复核人。高价值场景是**发出观点之前的证据核验**，而不是问 AI 明天买什么。

LLM 负责非结构化原文拆解、语义到指标的映射、阈值提取与无法验证事项识别。它能把“跑赢”“成交额放大”等不同表达变成统一计划。规则只做有限合规拦截、数值计算、窗口对齐与判定，避免模型自行心算或“补数”。搜索或传统终端能提供数据，但仍由人跨页拼接句子、口径、字段与结果；本产品把该过程封装成可复查的主张级任务。

模型响应必须是 1–5 条逐字原文引用，指标、比较运算符和数值类型通过白名单校验。用户确认后执行只读工具。服务端签名计划有效 20 分钟，改动文本、标的或窗口必须重新拆解。`causality` 与 `unsupported` 永不被数值规则判为“支持”。未配置/失败的模型会停止 AI 流程，不能把固定示例冒充在线 AI。

## 数据来源与可追溯性

以实际调用成功为准，固定证据包最多包含 5 个扶摇 GET + 1 个 iFinD 报价工具（另有 MCP 初始化、通知和工具列表读取）。最多 2 路并发，不对 429 或业务失败隐藏重试。

| 来源 | 接口 / 工具 | 用途 |
| --- | --- | --- |
| 扶摇 | `/api/a-share/calendar/trading-days` | 确定应有完整交易日窗口 |
| 扶摇 | `/api/a-share/prices/historical`，`adjust=forward` | 个股 N 日收益和成交额比 |
| 扶摇 | `/api/a-share-index/prices/historical`，`000300.SH` | 沪深 300 同窗比较，指数不复权 |
| 扶摇 | `/api/a-share/valuations/snapshot` | 当前 PE TTM，不能推导历史估值分位 |
| 扶摇 | `/api/a-share/prices/snapshot` | 相对前收盘价的快照涨跌幅 |
| iFinD MCP | `stock_highfreq_quotes`，`symbols` / `indicators` / `data_mode=real_time` | 最新价同日容差核对 |

官方文档：[扶摇](https://fuyao.aicubes.cn/docs/)、[iFinD](https://mcp.51ifind.com/)。iFinD 官方技能安装指南也用于本地接入验证，Web 端将其只读 MCP 交互移植为 Worker 的 HTTPS fetch，不包含本地密钥文件。

每条源保留 URL、无密钥参数、HTTP/业务结果、原始响应、请求 ID（服务若提供）、抓取时间、数据字段时间。扶摇 `data.timestamp` 依接口表示数据就绪时间或最新 K 线时点，**不保证是单标的最后成交时刻**；iFinD `data.tables` 的 time 为返回的行时间。两者不能强行当成相同口径。源日期不一致时报告 `time_mismatch`，不宣称一致性通过。两个品牌也可能共享上游，报价一致不是独立第三方确认。

## 主要统计口径

- N 日区间涨跌幅：`(close[N] / close[0] - 1) * 100`，必须 N+1 根日线且与交易日历精确对齐。
- 相对沪深 300：个股区间涨幅减同窗口指数涨幅，单位**百分点**。
- 成交额比：末日成交额 / 窗口前 N-1 个交易日日均成交额，单位倍；不是成交量或传统量比。
- PE TTM：原始快照值，单位倍；负值或空值不作常规估值解释。
- 最新完整交易日：Asia/Shanghai 16:00 之前用前一个交易日，之后要求当日日线；这是保守操作策略，不是数据商 SLA。
- 数值展示为两位小数，比较使用原始精度；`eq` 使用绝对容差 0.01（指标原单位）。

## 状态、人机协作与风险控制

状态：编辑 → 规划/失败 → 等待确认 → 取证/逐源失败 → 支持/不支持/未知 → 待复核/已确认/需修订 → 导出草稿或复核记录。

拒绝缺失、重复、非正价格和零分母；空值不补零；过期估值降为未知；冲突源的行情主张不生成正常判定。因果解释缺少原文和替代解释检验时保留未知。产品不执行交易，不输出确定性涨跌预测、收益承诺或直接买卖建议。

当前 HTTP 输入校验与同源检查、客户端模型地址白名单、服务端参数构造、HMAC 计划凭证、每实例 IP 请求限制提供原型防护。**它们不等同生产安全/法律认证**：分布式全局配额、强身份、租户隔离和不可篡改审计尚未实现；本地日志可以被浏览器用户修改。应在公开访问量较大之前补齐持久化配额与滥用保护。

## 已知边界与未做事项

- Web UI 暴露 5 个 A 股样本标的、5/10/20 日窗口，核心计算支持标准 A 股完整代码。不包含组合、账户、执行交易和荐股能力。
- 只有原文出现且能映射到白名单指标的数字主张可以机器判定。模型仍可能误解否定、比较和多标的；因此必须人工确认计划。
- 未做公告/政策原文检索与因果检验，不能因为涨价就归因于政策或资金。
- 模型未配置时，真实固定示例取证可操作；自定义观点需要用户提供实际模型服务。本交付若没有模型密钥，不宣称生产模型主链路已实测。
- 记录仅保存在当前浏览器，最多 8 条；未做团队共享、服务器持久化和真实用户认证复核签名。
- 数据许可、第三方再分发授权、投顾资质与适当性应在商业上线前单独审查。
- 尚未进行真实研究员访谈、配对实验或效率收益验证。目标不是已实现指标。
